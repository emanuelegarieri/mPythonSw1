# Green Kitchen Adventure

Emanuele Garieri

## Game

Green Kitchen Adventure is an adventure about a community kitchen that produces too much waste. 
The player's objective is to collect items and help make the kitchen more sustainable.

The game is suitable for minors and does not contain violent or inappropriate content.

## Commands

- `mission` displays the objective of the game.
- `collect` asks the player for an item and adds it to the inventory.
- `inventory` displays the collected items.
- `tip` displays a sustainability tip.
- `exit` closes the game.

## Sustainable development

The game is connected to Sustainable Development Goal 12: Responsible Consumption and Production. 
Its theme focuses on reducing food waste, reusing ingredients and making more responsible choices.

## Current functionality

The current Project 3 version:

- asks for the player's name and age;
- closes if the player is under 12;
- displays a main menu until the player enters `exit`;
- uses separate functions for the menu commands;
- allows the player to add items to an inventory list;
- displays the contents of the inventory;
- provides information about the mission and sustainability.
